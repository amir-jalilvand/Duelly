# Duelly Frontend

Telegram Mini App — React + Vite + TypeScript.

## Design system

Installed via `ui-ux-pro-max-cli` → [design-system/duelly/MASTER.md](design-system/duelly/MASTER.md)

- Style: Claymorphism (soft 3D, press feedback)
- Brand colors from logo: `#407BFF` / `#EA526F` / `#EFF1ED` / `#161616`
- Type: Fredoka (display) + Nunito (body)

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Flow

Splash → Language → Home → XO competitor → Difficulty → Starter → Play
